# SoftCombatDuels 🗡️🛡️

**SoftCombatDuels** es un mod para Minecraft (desarrollado para **NeoForge**) diseñado para recrear la experiencia del softcombat (combate con armas de gomaespuma o *boffers*) dentro del juego. Introduce un sistema de combate estructurado mediante duelos, mecánicas de parada, armas personalizadas y tabardos para facciones o equipos.

---

## 🛠️ Características Principales

* **Armas de Softcombat (Boffers):** Variedad de armas diseñadas para duelos equilibrados (Espadas cortas, espadas bastardas, grandes espadas, lanzas, estoques/q-tips y dagas)[cite: 1].
* **Escudos y Equipamiento:** Escudos redondos y tabardos personalizables con diseños de diferentes facciones o reinos (Ironheim, Templario, Reginae Discordia, etc.)[cite: 1].
* **Sistema de Duelos:** Comandos y menús interactivos para retar a otros jugadores a combates justos[cite: 1].
* **Soporte Multilenguaje:** Disponible en inglés (`en_us`) y español (`es_es`)[cite: 1].

---

## 📦 Descargas

Puedes descargar las versiones oficiales y estables del mod directamente desde nuestra página de **[CurseForge](https://www.curseforge.com/minecraft/mc-mods/softcombatduels)** o desde la sección de **[Releases](../../releases)** de este repositorio[cite: 1].

## ⚙️ Requisitos

* **Minecraft:** `1.21+` (según la versión del mod)
* **Mod Loader:** [NeoForge](https://neoforged.net/)

---

## 🚀 Compilación y Desarrollo

Si deseas compilar el mod desde el código fuente o contribuir al proyecto, asegúrate de tener instalado Java y ejecuta los siguientes comandos en tu terminal:

```bash
# Clonar el repositorio
git clone [https://github.com/TU_USUARIO/SoftCombatDuels.git](https://github.com/TU_USUARIO/SoftCombatDuels.git)

# Entrar al directorio
cd SoftCombatDuels

# Compilar con Gradle (Windows)
gradlew build

# Compilar con Gradle (Linux / Mac)
./gradlew build
